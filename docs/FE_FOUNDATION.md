## Thêm trang / route / chuỗi
- **Màn hình:** sửa `pages/SXX-*/index.tsx` (đang là `ScreenPlaceholder`). Route đã khai báo đủ trong `app/router.tsx`; muốn thêm route con: thêm mẫu vào `patterns` + builder vào `paths` (`routes.ts`), rồi 1 dòng trong `router.tsx` (lazy `const SXX = lazy(...)`). Luôn link bằng `paths.*`, mở modal bằng `<Link preventScrollReset>`.
- **S06/S07 (route modal):** trang tự render `<Modal open onClose={useModalClose()} …>`; router đã bọc `ModalBackground` vẽ màn gọi phía sau. Đóng = quay lại màn gọi, nếu mở link trực tiếp thì về `paths.group(groupId)`.
- **Bảo vệ:** mọi route trừ `/login`, `/__kit` nằm dưới `RequireAuth` (chưa đăng nhập → `/login?next=…&invite=…`; S00 sau khi thành công gọi `auth.signIn(authResponse)` rồi `navigate(resolvePostLoginPath(search), {replace:true})`). 404 (BE trả cho người ngoài nhóm) và 403 đã có trang thân thiện.
- **Chuỗi i18n:** thêm khóa vào `i18n/vi.ts` (không hard-code chữ trong JSX); dùng `const t = useT(); t('nhóm.khóa', {tham_số})` — khóa được kiểm tra lúc biên dịch. Thêm tiếng Nhật: tạo `ja.ts` kiểu `Messages`, đăng ký trong `i18n/locales.ts`.
- **Thời gian/điểm:** `useFormatters()` → `dateTime(iso)` (`dd/MM/yyyy, HH:mm` theo múi giờ nhóm), `relative`, `pointsLabel(PointAmount, {signed})` (chỉ ghép `percentLabel` do server trả, không tự tính điểm).

## Gọi API
`import { api, newIdempotencyKey } from '@/api'` — đường dẫn tương đối `/api/v1` (đúng khóa trong `ApiEndpoints`): `useQuery({ queryKey, queryFn: ({signal}) => api.get<Group>(`/groups/${id}`, {signal}) })`; `useMutation({ mutationFn: (b) => api.post<R>(path, b) })`. Tự gắn `Authorization: Bearer`; 401 → xóa phiên → S00; lỗi ném `ApiError{status,code,message,fieldErrors,traceId}` (`getErrorMessage(err,t)`, form: `applyFieldErrors(err, form.setError)`). `Idempotency-Key` tự thêm cho endpoint trong `IDEMPOTENCY_REQUIRED/RECOMMENDED`; muốn thử lại cùng thao tác: tạo khóa 1 lần rồi truyền `{ idempotencyKey }`. Đăng nhập: `api.post('/auth/login', body, { anonymous: true, skipUnauthorizedHandler: true })`. QueryClient: không retry 4xx; khóa cache dùng chung ở `app/shellApi.ts` (`queryKeys.unread` để invalidate sau khi đọc thông báo).
